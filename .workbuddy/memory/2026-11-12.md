## 登录页重构 + H5 双端分离

### 背景
用户要求去掉登录前设置头像/昵称步骤，用默认值；并明确 login.vue 是微信小程序专属页，H5 登录页要单独写。

### 已完成
- `src/pages/login/login.vue`：删除 `profile` 步骤（chooseAvatar + nickname 输入），流程压成「选择登录方式 → 手机号验证码」两步；默认身份 昵称「微信用户」/ 头像 `/static/logo.png`，仅前端兜底不写库。
- 修 bug：`finishLogin` 调用了 `router.isTabPage()`，但 router 对象只有 push/replace/reLaunch/switchTab/back，`isTabPage` 是模块级命名导出 → 改为 `import { isTabPage }`。此前带 returnUrl 的登录成功后会抛 TypeError 卡在登录页。
- 新增 `src/pages/login/login-h5.vue` + `login-h5.scss`：H5 独立登录页（手机号 + 短信验证码），别名 `loginH5`。
- `src/utils/router.js` 新增导出 `LOGIN_PAGE = { route, path }`，按平台返回 login / loginH5，统一"去登录"入口。
- 接入点改造：`src/utils/request.js`（401 跳转，含"已在登录页"判断）、`src/pages/mine/mine.vue`（主动登录）。
- `src/pages.base.json` 注册 `pages/login/login-h5`（默认导航栏，未设 custom）。
- `src/api/user.js` 新增 `h5SendLoginVerifyCode` / `h5Login`，路径为 `/TODO/...` 占位待替换。
- `src/stores/user.ts`：`isProfileReady` 加注——不再作为登录前置条件。

### 待办 / 风险
- H5 两个登录接口路径仍是占位，需替换为实际接口（页面层不用改）。
- 手机号快捷登录确认走旧版协议（`encryptedData + iv`）；若基础库只回 `code`，页面引导用户改用短信登录。

- 默认头像仍用 logo，建议补中性素材。

- 页面路由唯一入口：主包改 `src/pages.base.json`，分包改各自 `pages.config.mjs`；`src/pages.json`、`src/utils/routes.ts` 自动生成禁改。

## 登录用户信息写入（netUser）
- 澄清接口契约：`POST /api/miniApp/user/bind` 与 `GET /yacht/query-userinfo-by-union-id` 返回同构 —— `{ sysdate, netUser: {...}, error, message }`，用户字段在 `netUser` 里，不是扁平结构。
- 原 `bindUser` 直接 `setLoginResult(data)` 读扁平字段 → 实际什么都写不进去，`isLoggedIn` 恒 false（登录成功但页面仍当未登录）。已修复。
- `src/stores/user.ts` 新增 `setNetUser(netUser)`：凭证字段（openId/unionId/accessToken/coAccountId→accountId/coAppId/mobileNum）入持久化；资料字段按白名单 `USER_DETAIL_KEYS` 入 userInfo；`name`↔`nickName` 互兜底；`avatar`/`avatarUrl` 统一到 avatarUrl。
- `setLoginResult(data, phone)` 改为自动识别 `data.netUser` 嵌套或扁平，委托 `setNetUser`，并作为唯一写入口。
- `src/utils/login.js` 静默登录与 H5 Mock 改为直接调 `setNetUser`，去掉原先「setLoginResult + setNetUserId + setUserInfo」三连。
- `src/pages/login/login.vue` `bindUser`：bind 后校验 `netUserId` 存在，缺失则抛错不当成功；`isNewUser` 兼容 1/'1'/true。
- `src/pages-common/personInfo/personInfo.vue`：资料列表由假数据改为 computed（昵称/手机号取 store，真实姓名与身份证无后端字段则整行隐藏），新增 maskPhone/maskName/maskIdCard。
- `src/types/index.ts`：`UserInfo` 补 `email` / `centerId` / `realName` / `idCard` + 索引签名。
- 校验方式：`@vue/compiler-sfc` 编译三个 SFC 通过；esbuild 解析 store TS 通过。
